## Overview
- This repository provides the datasets used in the experiments presented in the paper ***A Model of Causal Explanation on Neural Networks for Tabular Data*** written by T. Isozaki, M. Yamamoto and A. Noda (https://www.sciencedirect.com/science/article/pii/S1877050925021696). The bibliographic information is listed below.
- These datasets were prepared ***to evaluate causal, explainable AI (causal XAI) methods*** in the field of tabular data and are intended for use in similar evaluations.
- The repository contains three synthetic datasets and ten pseudo-real datasets.
- For details on each dataset and the experimental procedures, please refer to the corresponding directories.
